AIR BANK DEMO – PWA PACKAGE

Tento balíček je určený jako neoficiální demonstrační prototyp. Není to skutečná bankovní aplikace a nemá se používat ke sběru skutečných přihlašovacích údajů.

GITHUB PAGES
1. Vytvoř nový GitHub repository.
2. Nahraj obsah tohoto adresáře přímo do ROOTU repository (index.html musí být nahoře, ne uvnitř další složky).
3. V repository otevři Settings > Pages.
4. Source: Deploy from a branch.
5. Branch: main, folder: /(root), potom Save.
6. Počkej na dokončení deploymentu a otevři URL, kterou GitHub Pages ukáže.

IPHONE
1. Otevři GitHub Pages URL v Safari.
2. Share / Sdílet.
3. Add to Home Screen / Přidat na plochu.
4. Potvrď Add / Přidat.
